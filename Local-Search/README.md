# Module 3 Assignment: Local Search

## Overview

This project implements Hill Climbing algorithms for two optimization problems:

1. **Eggholder Function:** Minimize a nonlinear mathematical function.
2. **N-Queens Problem:** Arrange N queens on an N×N chessboard without any queens attacking each other.

Both problems demonstrate how local search algorithms improve an initial solution and how they can become trapped in local minima.

## Part 1: Eggholder Function

### Objective

Minimize the Eggholder function:

\[
f(x,y)=-(y+47)\sin\left(\sqrt{\left|\frac{x}{2}+y+47\right|}\right)-x\sin\left(\sqrt{|x-(y+47)|}\right)
\]

where x and y are constrained to the interval [-512, 512].

The known global minimum is approximately **−959.640663**, located at (512, 404.2319).

### Implementation

The algorithm begins with randomly generated x and y coordinates.

Neighboring solutions are generated by applying small random changes to both coordinates:

- x' = x + (random() − 0.5)
- y' = y + (random() − 0.5)

Each candidate is evaluated using the Eggholder function. A candidate is accepted only if it produces a lower function value.

The algorithm terminates after 100 consecutive unsuccessful improvement attempts.

### Experimental Results

The algorithm was executed 100 times using different random starting points.

| Metric | Result |
|---|---:|
| Total runs | 100 |
| Best minimum | −959.628317 |
| Worst minimum | 523.675778 |
| Mean minimum | −475.723075 |
| Median minimum | −507.873732 |
| Known global minimum | −959.640663 |

The best observed result was close to the known global minimum, but many trials converged to less optimal solutions.

### Analysis

The Eggholder function contains numerous local minima. Consequently, Hill Climbing can converge to different results depending on the initial coordinates.

The distribution of the 100 final function values demonstrates that the algorithm frequently becomes trapped in local minima rather than reaching the global minimum.

Random initialization provides some exploration of the search space across independent trials, but it does not guarantee an optimal solution.

The experimental distribution is saved as `eggholder_distribution.png`.

## Part 2: N-Queens Problem

### Objective

Place N queens on an N×N chessboard such that no two queens attack each other.

The objective function counts the number of attacking queen pairs. A valid solution has an objective value of zero.

### Implementation

The chessboard is represented as a Python list containing one queen per column. Each list value specifies the row containing that column's queen.

The algorithm begins with a randomly generated board.

At each iteration, it evaluates every neighboring configuration produced by moving one queen to another row within its column.

It selects the neighbor with the lowest number of attacking pairs, provided that the move improves the current configuration.

The algorithm terminates when either:

- A valid solution is found with zero attacking pairs.
- No neighboring configuration offers an improvement.

This approach is known as steepest-descent Hill Climbing.

### Experimental Results

The algorithm was executed 100 times for each board size.

| Board size | Trials | Successful solutions | Success rate |
|---|---:|---:|---:|
| 8 Queens | 100 | 11 | 11% |
| 16 Queens | 100 | 2 | 2% |
| 32 Queens | 100 | 1 | 1% |

Across all 300 trials, 14 valid solutions were found, producing an overall success rate of approximately 4.67%.

### Analysis

The experiments showed that the success rate decreased as the board size increased.

For N=8, the algorithm successfully solved 11% of the trials. The success rate declined to 2% for N=16 and 1% for N=32.

Although the algorithm often significantly reduced the number of attacking pairs, it frequently stopped before reaching a valid solution.

This occurred because the algorithm only accepted moves that strictly improved the objective function. When no improving neighbor was available, it terminated, even if queens were still attacking each other.

The results demonstrate the limitations of basic Hill Climbing when navigating increasingly large search spaces.

### Board Visualizations

For each board size, the initial and final configurations from the first 10 trials were saved.

The `nqueens_plots/` directory contains 30 images, each displaying the initial and final chessboards side by side.


## Conclusion

The experiments demonstrate both the usefulness and limitations of Hill Climbing.

For the Eggholder function, the algorithm occasionally approached the known global minimum but frequently converged to local minima.

For N-Queens, the algorithm improved the number of attacking pairs in many trials but often failed to produce a valid solution.

The results highlight the importance of search-space characteristics, initialization, and the neighborhood structure when applying local search algorithms.

Potential improvements include random-restart Hill Climbing, sideways moves, and simulated annealing, which may help the algorithm escape local minima.
